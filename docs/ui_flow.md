# SPOT CHECK 화면 흐름

실행: `venv/Scripts/python.exe -m streamlit run app.py`

1. 소개: 사진 없이 서비스 안내와 분석 시작 버튼. 화면 너비 제한 없이 브라우저 영역을 사용한다.
2. 지역 선택: 동성로·수성못·동대구역·칠곡3지구 카드와 네이버 지도. 검색으로 지역을 필터링한다.
3. 위치 설정: 정확한 주소 분석 또는 스팟 내 위치 추천을 선택한다. 주소 검색은 수집 상가의 도로명·건물번호를 사용한다. 좌표 직접 입력도 지원한다. 반경은 100/200/300/500m.
   주소를 입력하지 않아도 선택한 지역의 수집 주소 목록에서 검색·선택할 수 있다.
4. 채팅: 선택 정보, 업종 바로가기, 대화, 현재 세션 분석 기록, 상세 지도와 JSON 다운로드.
   분석 지역 선택창에서 동성로·수성못·동대구역·칠곡3지구로 바로 전환할 수 있다. 전환하면 해당 지역의 위치 설정 화면으로 이동한다.

지역별 대화와 분석 기록은 브라우저 세션 안에서 유지된다. 영구 저장은 하지 않는다.
지도 클릭으로 위치를 지정하는 기능은 아직 연결하지 않았다. 주소 검색이나 직접 좌표 입력을 사용한다.
교통 분석과 외부 PDF 문서 RAG는 현재 채팅에 연결하기 전이다. 화면은 실제 CSV 기반 집계·후보 비교만 안내한다.
900px 이하에서는 열이 세로로 배치되며, 모바일에서는 제목 크기와 간격을 줄인다.
카페·미용실·여성 의류 등 명확한 업종은 로컬 분류 목록으로 처리하므로 GMS 연결 없이 집계 가능하다. 그 외 자연어 해석에는 GMS를 사용하며 연결 실패 시 지원 업종 입력을 안내한다.

검증: `venv/Scripts/python.exe -m unittest discover -s tests -v`
브라우저 확인: 서버 실행 후 `venv/Scripts/python.exe scripts/check_ui_browser.py` (Windows Edge 필요). 화면 캡처는 `data/processed/ui_preview/`에 저장한다.
