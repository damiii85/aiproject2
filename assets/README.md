# 시작 배너와 UI 참고

`hero_city.png`: 사용자가 제공한 `위치 데이터 분석 도시의 미래.png`를 원본 그대로 복사한 시작 배너. 배경 위 문구·버튼은 Streamlit UI로 별도 표시한다. 이미지 안의 차트는 장식이며 실제 상권 통계가 아니다.

채팅 화면은 사용자 제공 `SPOT CHECK 상권 분석 대시보드.png`의 최근 대화·채팅·통계 패널 배치를 참고했다. 시안의 예시 임대료·프랜차이즈 비율·월평균 유동인구·상가 사진과 주소는 실제 데이터로 취급하지 않고 사용하지 않는다.
