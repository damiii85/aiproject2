파일명 권장 형식: `기관_분석지역_업종_기준연월.pdf`

예: `소상공인365_실제분석행정동_카페_202609.pdf`

기준연월은 PDF에 표시된 데이터 기준으로 적으세요. 출력한 날짜와 다를 수 있습니다.
같은 스팟에서 여러 행정동·업종의 PDF를 받아도 됩니다. 보고서가 다루는 실제 영역을 보존하세요.
파일명을 바꾸지 않고 원래 이름으로 저장해도 됩니다. 서로 다른 파일을 덮어쓰지만 않으면 됩니다.

가능하면 각 폴더의 `sources.csv`에 PDF 파일명, 원문 URL, 분석 지역, 업종, 기준일, 출력일을 기록하세요.
모르는 항목은 빈칸으로 두세요. 인증키나 로그인 토큰이 포함된 URL은 기록하지 마세요.
PDF 내부에 지역·업종·기준일이 보이는 상태로 저장하고, 차트와 표가 잘리는지 확인하세요.

이 폴더의 PDF와 출처 CSV는 Git에서 제외됩니다. 로컬 보관용이며 현재 앱의 RAG에 자동 반영되지 않습니다.
파일 확보 후 별도로 본문 추출·청킹·색인을 연결합니다.
